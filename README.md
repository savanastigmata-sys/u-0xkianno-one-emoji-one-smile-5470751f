One emoji, one smile: a deterministic Python program that writes exactly one emoji — the hugging face 🤗 — to `entry.txt`, the single emoji most likely to make a stranger smile. Warm at first glance, universal, picked rather than the default smiley, and right coming from a stranger. No words, no caption, no explanation.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (1 character, 4 UTF-8 bytes) into `$MAKEFUN_OUTPUT_DIR`, or `./output` when that is unset. Stdlib only, no network, no randomness — two runs are byte-identical.
